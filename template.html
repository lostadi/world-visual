How to read the computation

Each square is a cell holding up to four particles: east (bit 1), north (bit 2), west (bit 4), south (bit 8). On each tick, an east–west pair becomes a north–south pair, and vice versa. Particles then move one cell; crossing an edge wraps to the opposite edge.

Collision view highlights masks 5 and 10 in the displayed frame: these are candidates for the next update. The plots show cumulative collisions through the selected tick. Momentum uses the source convention: north is positive py.

Execution evidence and provenance

This is a recorded O execution, with all 129 states per world captured inside the original Python update loops. Playback displays stored states; it does not rerun the simulation in JavaScript. The original world.O is unchanged. Its 32 CRC checkpoints, SQLite aggregate and four final SHA-256 hashes passed the source's oracle comparison.
